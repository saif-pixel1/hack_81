### How this card works

The banner above is **not static** — it's generated by [`scripts/generate_card.py`](scripts/generate_card.py) using
a mix of two sources:

| Comes from **live GitHub data** (auto, no editing) | Comes from **`profile-config.yml`** (you edit) |
|---|---|
| Repos, Stars, Forks, Followers | Role |
| Commits, PRs, Issues | Major / field of study |
| Top repo, Languages | Currently learning |
| Contributions & Reviews (last 12 months) | Location, Email, Twitter |
| Account uptime | |

A [GitHub Action](.github/workflows/update-card.yml) re-runs the script **every day**, and also instantly whenever
you push a change to `profile-config.yml` — so the card always reflects your current GitHub stats.

### ✏️ To update your role / major / learning / contact info

1. Open [`profile-config.yml`](profile-config.yml).
2. Edit the values (they're plain text, no code involved).
3. Commit the change.

That's it — the Action regenerates `images/light_mode.svg` and `images/dark_mode.svg` and commits them back
within a minute or two, and your GitHub profile page updates automatically.

### 🔧 One-time setup on your repo

1. Make sure this repo is named **exactly** `saif-pixel1` (matching your username) so GitHub treats it as your profile repo.
2. Push everything as-is: `README.md`, `profile-config.yml`, `images/`, `scripts/`, `.github/`.
3. Go to the repo's **Actions** tab and run "Update profile card" once manually (`workflow_dispatch`) to generate the
   first live version — otherwise the checked-in SVGs will keep showing today's placeholder numbers until the
   schedule kicks in.
4. No extra token setup needed — the workflow uses the built-in `GITHUB_TOKEN` GitHub provides automatically.
